## 🚀 Projetos

### 🤖 YaannkAgent
Assistente pessoal via WhatsApp com IA local, RAG e integração com Obsidian.
Construído com FastAPI, Ollama, SQLite e WhatsApp API. Nasceu de um problema real.

### 📰 DOERJ Monitor
Pipeline Python que monitora o Diário Oficial do RJ, processa PDFs com LLM (Gemini/DeepSeek) e distribui boletim executivo por e-mail para mais de 20 destinatários. Em produção.

### 📋 Controle de Prazos SEI
Canvas App no Power Apps com motor de SLA e alertas automáticos via Power Automate para controle de prazos de processos em 4 áreas.

### 📊 Dashboard de Gestão de Riscos
Power BI com 72 tabelas, 19 medidas DAX e heatmap 5×5 cobrindo 13 áreas organizacionais.
